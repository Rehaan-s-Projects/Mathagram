Unit 1 — Checkers (Draughts)

Basic Moves

Both the black and red pieces follow the same rule for a basic (non-capture) move: one square diagonally forward, onto an empty dark square. Sideways or straight-ahead moves are not allowed.

A black piece can move to either dashed square — diagonally forward, one square.

  • Move diagonally only — never straight or sideways.
  • Move forward only (until you become a king).
  • Move one square per turn, unless you're jumping a capture.
  • Land only on an empty dark square — never on a light square or on top of another piece.
  • Black usually moves up the board; red moves down. (Direction depends on which side each player chose, but each side always moves forward.)

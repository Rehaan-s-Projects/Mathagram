🧠 Memory Athletics

Train your memory like a world-champion mnemonist. Build memory palaces (Method of Loci), master the Major System & Person-Action-Object, memorize a deck of cards, recite π to a thousand digits, learn names & faces, ace exams without cramming, deliver speeches without notes, and study the World Memory Championships, the science of forgetting (Ebbinghaus), spaced repetition, sleep consolidation, false memories, eyewitness testimony, eidetic-memory myths, and the lives of memory athletes from Tony Buzan to Joshua Foer to Dominic O'Brien. 75 units, 1125 lessons.

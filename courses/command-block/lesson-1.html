What Is a Command Block?

A command block is a special block in Minecraft that runs a command whenever it gets a redstone signal. You can't craft one — you only get them by typing /give @s command_block in a world with cheats enabled.

There are three types, and they all look like a grey block with arrows on top — but the colour of the centre tells you what they do.

IMPULSE
Runs once when it gets a signal.
REPEAT
Runs every tick while powered.
(20 times per second!)
CHAIN
Runs after the previous block.

Tap a block above

Click any of the three command blocks to learn what makes it special.

▶ Examples In Action

give @p diamond_sword
Hand the nearest player a diamond sword the moment the block is powered.
IMPULSE
tp @s 0 100 0
One-shot teleport to coordinates 0, 100, 0 — a classic return-to-spawn button.
IMPULSE
effect give @a speed 1 1
Re-applies a 1-second Speed II to every player every tick — a permanent fast-zone.
REPEAT
say Phase 2 begins!
Place behind another block — fires only AFTER the previous command succeeds.
CHAIN
setblock ~ ~-1 ~ diamond_block
Drops a diamond block right under your feet — handy when you need a safety save.
